# Spumcake Docs — overview

Spumcake Docs is the public documentation of Spumcake, an AI-native entertainment and technology company, for platform users and Spumcake Studio users. It covers the platform, the sites under spumcake.tv and the mobile app, and Spumcake Studio, the open-source desktop app. It is where people learn to use them, and where Studio's users learn to extend it, such as by writing their own skills.
